# FineVu CLOUD & Wi-Fi · Web Demo

파인뷰 CLOUD & Wi-Fi 앱(Android)을 실제 블랙박스 없이 웹에서 시연하는 프로토타입입니다.
BLE/Wi-Fi 연결, 클라우드 등록, 원격 라이브 뷰·설정·업데이트, 푸시 알림을 가상으로 재현합니다.

- 웹 보기: https://fine-proto.github.io/FineVu_Cloud/ (GitHub Pages 활성화 시)
- 영어로 바로 열기: `?lang=en`
- 시연 모델: **X3700 POWER** (BLE/Wi-Fi · LCD, 인증번호 연결) / **X600** (CLOUD · BLE/Wi-Fi, REC 버튼 페어링)
- 왼쪽 DEMO 패널(모바일은 오른쪽 아래 DEMO 버튼)에서 가상 블랙박스 버튼 누르기, 주행/주차 전환, 충격 발생, 클라우드 연결 끊김, 새 펌웨어 알림 등을 실행할 수 있습니다.
